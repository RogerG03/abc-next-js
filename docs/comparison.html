Antes nada se hacía cumplir

  1. Editor
  2. Hook pre-commit (ejemplo sin instalar)
  3. Convención de commits
  4. Checks antes de push

  6. CI (comentado)

Ahora CI sólo confirma

  1. pnpm install: Node 24.20.0 + hooks
  2. Editor
  3. pre-commit: formato, lint, secretos
  4. commit-msg: Conventional Commits
  5. pre-push: pnpm check
  6. PR con Definition of Done
  7. CI: check, build + E2E, seguridad
  8. main → Pages

Saltos de línea Sin .gitattributes; avisos CRLF en Windows. * text=auto eol=lf. Checkout
Arquitectura Límites sólo descritos en la skill y en AGENTS.md. no-restricted-imports bloquea shared → modules/app/server, modules → app e imports internos entre módulos. Editor y commit

Formato y lint Manual; Oxlint sólo con la categoría por defecto. Sobre archivos staged al hacer commit; correctness + suspicious como errores. Commit
Secretos Sin escaneo. gitleaks en pre-commit (opcional) y en CI sobre todo el historial (obligatorio). Commit y CI

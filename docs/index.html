Arranque

Tres comandos y los estándares ya están activos

  • pnpm descarga Node 24.20.0 si hace falta y lo fija en el lockfile.
  • pnpm install instala los hooks de Git con Lefthook.
  • Antes de abrir un PR, pnpm check debe pasar; el hook pre-push lo ejecuta solo.
abc-next-js 
$ git clone {{ site.repository_url }}.git
$ cd abc-next-js
$ pnpm install   # Node 24.20.0 + hooks de Git
$ pnpm dev

# antes de push (lo ejecuta el hook)
$ pnpm check
